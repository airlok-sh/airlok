# airlok

Деплой для тех, кто собрал приложение с помощью ИИ и не хочет разбираться с серверами. Вы отмечаете в манифесте, что нужно приложению (база данных, загрузка файлов и т. п.), а рецепт настраивает чистый VPS, разворачивает проект из GitHub и закрывает всё, что не отмечено.

Всё в этом репозитории запускается на вашем сервере. Это обычные bash-скрипты, их можно прочитать целиком перед запуском.

## Что внутри

| Каталог | Что |
| --- | --- |
| [recipes](recipes) | рецепты: настройка сервера, песочница и деплой приложения, деплой из GitHub и по push, агент для выкатки кнопкой из дашборда, Let's Encrypt, проверка доступности и метрики, уведомления |
| [checkup](checkup) | проверка сервера только на чтение: SSH, открытые порты, файрвол, обновления, бэкапы, Docker, nginx |
| [examples](examples) | примеры проектов: с манифестом `airlok.yml` и без него |

С чего начать — [recipes/README.md](recipes/README.md).

## Состояние

Ранняя версия. Рецепты проверены на Ubuntu 24.04: Next.js, Node (Express, Nest, Fastify…), Python (FastAPI, Flask, Django, Streamlit), статические сайты и фоновые боты, с PostgreSQL и загрузкой файлов. `airlok.yml` необязателен — стек определяется по файлам проекта.
