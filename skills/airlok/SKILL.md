# airlok

airlok собирает проект и публикует его — на хостинге airlok (свой сервер не нужен) или на своём сервере пользователя, где
стоит агент airlok. Где живёт приложение, видно по полю `hosted` в `list_apps`.

У тебя два инструмента:

- **MCP-сервер `airlok`** — приложения и серверы, выкатка из GitHub, статус и лог сборки, переменные, логи, база,
  домены и настройки. Если инструментов airlok нет, попроси человека один раз выполнить `npx @airlok/cli setup` и
  перезапустить агента.
- **CLI `npx @airlok/cli`** — проверка проекта (`check`), выкатка папки на хостинг без GitHub (`deploy`), переменные
  своего сервера (`env`), подключение своего сервера (`server connect`). С `--json` итог — одной строкой.

## Сначала — guide

Подробные инструкции отдаёт инструмент MCP `guide` с темой. Они меняются вместе с airlok, поэтому вызывай его перед
делом, а не по памяти:

- `deploy` — выкатить, следить за сборкой и чинить её, проверить сайт;
- `env` — переменные окружения и секреты;
- `data` — где хранить данные, база в файле, миграции, опасные команды;
- `manifest` — `airlok.yml` и проверка проекта;
- `rules` — правила airlok для `AGENTS.md` проекта;
- `server` — свой сервер: подключить VPS, доступ по SSH;
- `domains` — свой домен;
- `settings` — настройки приложения на хостинге.

## Всегда

- Данные приложение хранит только в базе (`DATABASE_URL`) или загрузках (`UPLOAD_DIR`). Папка проекта на сервере только
  для чтения, а `/tmp` очищается при перезапуске: не переноси туда файл базы, даже если так пропадает ошибка.
- Секреты — только в переменных окружения: не в код, не в коммит, не в аргументы команд. В ответах — имя и последние
  четыре символа значения.

## Чего не делать без явной просьбы человека

- создавать приложения, выкатывать в рабочее приложение, менять переменные, домены и настройки сайта;
- удалять переменные (`delete_env`) и отключать домены (`domain rm`); приложения удаляются только в дашборде;
- запускать команды, которые стирают данные: `prisma db push --accept-data-loss`, `migrate:fresh`, `DROP`, `TRUNCATE`;
- печатать токены airlok (`airlok_pat_…`); коммитить `.env` и `.airlok/`.

Если что-то нельзя сделать инструментами, дай ссылку на дашборд: `dashboard_url` из `get_app` или https://app.airlok.ru.
